# 3-minute demo script

Record the phone screen with audio. Keep every claim true to what is on screen.

**0:00 to 0:10, disclosure (required first line)**
"Everything in this project was built during the hackathon, and no code from any earlier project is used."

**0:10 to 0:35, the problem**
Show a textbook diagram. "Screen readers can read the caption. They cannot tell a blind student where the sun is, how big the mountain is, or what sits next to what. Touch Atlas makes the picture itself touchable."

**0:35 to 1:35, the demo (eyes closed or screen covered)**
Choose a real picture. While it loads, say what is happening: "Muse Spark names the parts. SAM 3.1 draws the exact outline of each." Drag across it. Let the audience hear each part speak and see the outline follow your finger. Rest on empty space and let it say which way the nearest part is. Double tap for detail.

**1:35 to 2:10, Ask**
Touch one part, tap Ask, ask a question about it. Let the answer play.

**2:10 to 2:40, how Meta's models are used**
Show the one-line pipeline from the README. "Muse Spark decides what the parts are. SAM 3.1 returns pixel-accurate masks. The mask is what lets a finger land on a river or a lung, not just a rectangle."

**2:40 to 3:00, close**
"Open source, public repo, link below. Next: charts that read their values as you swipe along them."

Do not show or mention anything built before Oct 26.
